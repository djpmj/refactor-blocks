# 警告の矢印の説明が、隣の「循環」バッジの下に隠れる不具合を直す

## 背景・目的

循環依存のクラスどうし(中級1の `Order` ⇄ `Customer` など)は、行きと帰りの2本の警告の矢印(`WarningEdge`)を持ち、
どちらにも「⚠ 循環」のバッジが出る。片方のバッジを押して説明(`.warning-edge__popover`)を開くと、
**もう片方のバッジが説明の上に重なり、文章が読めない**(報告あり)。

原因(ブラウザで確認済み): 各バッジの入れ物 `.warning-edge` が `position: absolute; z-index: 10` を持つため、
それぞれが独立した重なり順(スタッキングコンテキスト)になる。説明の `z-index: 20` はその入れ物の中でしか効かず、
DOM で後ろにある別の `.warning-edge`(同じ `z-index: 10`)が説明より前に描かれる。
開いている側の入れ物の `z-index` を上げると、説明が前面に出ることを確認した。

## 変更対象ファイル一覧

| パス | 層 | 新規/変更 | 役割 |
| --- | --- | --- | --- |
| `src/presentation/canvas/WarningEdge.tsx` | presentation | 変更 | 説明を開いているときだけ、入れ物に `warning-edge--open` クラスを付ける |
| `src/index.css` | presentation | 変更 | `.warning-edge--open { z-index: 30; }` を足す |
| `e2e/`(循環依存の警告を扱う既存のspec、無ければ `e2e/warning-edge.spec.ts` を新規) | E2E | 変更 | 中級1で説明を開くと、隣のバッジより前に出る(下記) |

`domain`・`application` の変更は無い。

## 振る舞い

- 警告のバッジを押して説明を開いている間、その入れ物は他のすべての警告バッジ(閉じているもの)より前に描かれる。
  説明は隣のバッジに隠れず、全文が読める
- 説明を閉じると、`z-index` は元の 10 に戻る(閉じたバッジどうしの重なりは今どおり)
- 説明は同時に1つしか開かない(`useWarningEdgeState` の `openId`。今どおり)ので、開いているものどうしの重なりは考えなくてよい
- 開閉の操作(クリック・Esc・外側のクリック)、説明の文面、バッジの位置は変えない

## データ・型の変更

なし。

## TDD対象の純粋関数

なし(CSS の重なり順と、クラス名の付け外しだけ)。E2E で守る。

## 受け入れ基準

- `npm run check` が通る
- `npm run test:e2e` が通る
- 中級1「循環依存を断ち切る」で、`Order` ⇄ `Customer` の上側の「循環」バッジを押すと、説明が下側の「循環」バッジより前に出て、
  「2つのクラスが互いに呼び合っています」から最後の行まで隠れずに読める
- 下側のバッジを押したときも同じ(どちらを開いても前に出る)
- 説明を閉じると、両方のバッジが今どおり表示される

E2E: 中級1を開き(幅の広いビューポートで)、1つ目の `.warning-edge__button` を押す。2つ目のバッジの中心座標で
`document.elementFromPoint` を取り、それが `.warning-edge__popover` の中の要素であることを確かめる
(修正前は2つ目のバッジが返る)。

## スコープ外

- 2本の矢印のバッジを1つにまとめる・バッジ同士が重ならないように配置をずらすこと
- 説明をホバーで開く・ポップオーバーの位置を自動で反転させること
- 他のポップオーバー・ツールチップの重なり順の見直し
