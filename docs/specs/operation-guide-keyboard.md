# operation-guide-keyboard: 操作ガイドにキーボードだけで遊ぶ方法を書く

## 背景・目的

2026-10-17 に操作ガイド(ツールバーの「操作ガイド」、`OperationGuideDialog`)を読むと、ドラッグ・右クリック・ダブルクリック・クリックといった
**マウスの操作だけ**が書かれていた。実装にはキーボードの手段がある(メソッドなどのボタンは Tab で選べ、Space で持ち上げて矢印キーで動かせる
`KeyboardSensor`、右クリックメニューは Shift+F10 / メニューキーで開ける `move-via-context-menu`)が、どこにも案内が無いので気付けない。

ガイドの取り消し・やり直し(Ctrl+Z など)と、サイドバーの境界の矢印キーだけはキーボードの説明がある。

## 足す節「キーボードで操作する」

| 操作 | 説明 |
| --- | --- |
| `Tab` / `Shift+Tab` | クラス・メソッド・フィールドのブロックへ順に移ります。 |
| `Enter` | 選んだメソッドの中身を右側のエディタに開きます。 |
| `Shift+F10` / メニューキー | 選んだブロックの右クリックメニューを開きます。メニューの中は `↑` `↓` と `Enter` で選び、`Esc` で閉じます。別のクラス・ファイルへの移動もここからできます。 |
| `Space` → 矢印キー → `Space` | ブロックを持ち上げて動かし、置きます。`Esc` で取り消します。 |
| `?` | このガイドを開閉します。 |

- 各行の説明は、実際の動きと食い違わないように、実装時に1つずつ操作して確かめる。動かないものがあれば、その行は書かず、PRの説明に「動かなかった操作」として挙げる
- 既存の「右クリックメニュー」の節の説明の末尾に `キーボードでは Shift+F10 で開けます。` を足す

## TDD対象の純粋関数

## 受け入れ基準

1. 操作ガイドを開くと「キーボードで操作する」の節があり、上の5行が出る
2. ガイドに書いたキー操作は、すべて実際にその操作ができる(E2E で `Tab` → `Enter` でエディタが開くこと、`Shift+F10` でメニューが開くことを確かめる。自動操作で `Shift+F10` がブラウザのメニューイベントにならない場合は `ContextMenu` キーで確かめる)
3. `npm run check` と `npm run test:e2e` が通る
