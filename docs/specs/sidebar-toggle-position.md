# 左サイドバーの開閉ボタンを、サイドバーのすぐそばに移す

## 背景・目的

左の「課題とヒント」サイドバーの開閉ボタン(`«` / `»`)は、`src/presentation/stage/StagePanel.tsx` の画面最上部ヘッダー
(`<header className="stage-panel">`)の左端、ステージ名の左に置かれている。しかしサイドバー本体はヘッダーの下にあるため、
ボタンとサイドバーが離れていて「何を開閉するボタンなのか」が分かりにくい。特にサイドバーを閉じると、ボタンはヘッダーに残る一方で
サイドバーのあった場所は空になり、位置の対応が全く無くなる。

ボタンを**サイドバーの境界線のすぐ脇**(サイドバー右端の上部)に移し、サイドバーを開いても閉じても、境界線の位置に付いて動くようにする。
開閉の動作・状態管理・アクセシビリティ属性は変更せず、ボタンの置き場所と見た目だけの修正。

## 変更対象ファイル一覧

| パス | 層 | 新規/変更 | 役割 |
| --- | --- | --- | --- |
| `src/presentation/stage/StagePanel.tsx` | presentation | 変更 | 開閉ボタンを `<header>` から取り出し、`.app__body` 内のサイドバーとワークスペースの境目へ移す。`sidebarOpen` の `useState`・`aria-expanded`・`aria-controls`・`aria-label`・`title`・`onClick`・`«`/`»` の表示は変更しない |
| `src/index.css` | presentation | 変更 | ボタンの位置・見た目のスタイルを追加し、ヘッダー用の `.stage-panel > .icon-button`(75行目)は不要になるので削除する |

## 配置の仕様

- ボタンは `<aside id="stage-sidebar">` の**外**に置く(サイドバーは `hidden` で非表示になるが、ボタンは閉じていても必ず表示される必要がある)
- **開いているとき**: サイドバーの右端の境界線(260px幅の右端)の上に、境界線をまたぐ形で置く。縦位置はサイドバーの上端から少し下(目安 8〜12px)
- **閉じているとき**: キャンバス側の左端(サイドバーがあった場所の右端=画面左端)に、同じ縦位置で置く。つまり境界線の位置に付いて動く
- ボタンは縦長の小さなハンドル状(目安 幅20〜24px・高さ 36〜40px)。背景 `var(--surface)`・枠線 `var(--border)`・角丸、ホバーで枠線が `var(--accent)` になる。色の直書きはしない(ライト/ダーク両対応)
- キャンバス(React Flow)やツールバーに隠れないよう `z-index` を付ける。ボタンがキャンバスの操作(ノードのクリック・パン)を奪わない範囲の小ささにする
- ヘッダーの高さ・並び(ステージ名・ステージ選択・ボタン類)は、開閉ボタンが無くなる以外は変えない
- 実装は新しい依存を入れず、既存の `.app__body`(flex)に `position: relative` を足す程度の素朴なCSSでよい

## データ・型の変更

なし。ドメインモデルやPropsの型には影響しない。

## TDD対象の純粋関数

なし。表示位置のみの変更(`CLAUDE.md`「表示のみのコンポーネントはユニットテスト対象外としてよい」)。

プレイヤーの操作導線(ボタンの置き場所)が変わるため、E2Eは追加・更新する。

- `e2e/` に、サイドバーの開閉を確認するケースを追加する(既存に開閉のE2Eが無ければ新規 `e2e/sidebar-toggle.spec.ts`、あれば追記):
  1. `getByRole('button', { name: 'サイドバーを閉じる' })` をクリックすると、「課題とヒント」(`complementary`)が非表示になり、ボタンの名前が「サイドバーを開く」に変わる(`aria-expanded` が `false`)
  2. もう一度クリックすると再び表示される
  3. ボタンの位置がサイドバーの近くにある: 開いているとき、ボタンの `boundingBox().x` がサイドバーの右端(`boundingBox().x + width`)付近(±30px以内)にあり、閉じているときは画面左端付近(x が 40px 未満)にある。ヘッダー(ステージ名の左)には無い(`y` がヘッダーの高さより下)
- 画面幅は 1400px 以上で実行する(初期状態でサイドバーが開く幅。`playwright.config.ts` の設定を確認し、足りなければテスト内で `page.setViewportSize` する)

## 受け入れ基準

- `npm run check`(lint + typecheck + test)が通る
- `npm run test:e2e` が通る(既存のE2Eがボタンの位置変更で壊れていないこと。ボタンを `icon-button` クラスなどで探している箇所があれば、新しい場所に合わせて直す)
- サイドバーが開いているとき、`«` ボタンがサイドバーの右端の上部、境界線の上に表示される
- ボタンを押してサイドバーを閉じると、ボタンは `»` になって画面左端(キャンバスの左上)に残る。再度押すと開き、ボタンも境界線の位置に戻る
- ヘッダーには開閉ボタンが無く、ステージ名がヘッダーの左端から始まる
- Tabキーでボタンにフォーカスでき、Enter/Spaceで開閉できる(`<button>` のまま。フォーカスリングを消さない)
- ライトモード・ダークモードどちらでもボタンが見える
- 狭い画面(1400px未満)の初期状態(サイドバーが閉じている)でも、ボタンが画面左端に表示され、押せる

## スコープ外

- サイドバーの開閉アニメーション・幅のドラッグ変更・開閉状態の保存(`localStorage`)
- 右側のメソッドエディタなど他のパネルの開閉ボタンの追加・変更
- サイドバーの中身(課題・ヒント・説明)の変更
- 狭い画面での初期状態(1400px未満は閉じる)の判定ロジックの変更
