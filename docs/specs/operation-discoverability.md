# operation-discoverability: 統合・呼び出し元へ戻す・可視性の操作を見つけやすくする

## 背景・目的

中級9(コピペされた消費税計算を1か所にまとめる)で、重複した3つの処理を1つにまとめる方法を探した。

- 操作ガイド(`OperationGuideDialog`)には、ドラッグ・右クリック・名前の変更・抽出・取り消しは載っている。
  しかし**統合**(似た処理を持つメソッドを1つにまとめる)、**呼び出し元へ戻す**(Inline Method)、**可視性の変更**が載っていない
- 統合は、メソッドエディタの「似た処理を持つメソッド」の欄にあるボタンで行う。
  ところがボタンの文字は `InvoiceService.calculateInvoiceTax()` とメソッド名だけで、**押すと統合される**とは読めない(そのメソッドへ移動するリンクに見える)
- 統合後の名前の入力欄には `aria-label` しかなく、目に見えるラベルが無い。何のための欄か分からない
- 「呼び出し元へ戻す」ボタンには、何が起きるかの説明が無い

## 見た目・動きの仕様

### 操作ガイド

今の「処理を抽出する」の次に、次の3項目を足す(今の項目と同じ「操作の名前 / 操作のしかた / 説明」の形)。

| 操作の名前 | 操作のしかた | 説明 |
| --- | --- | --- |
| 似た処理をまとめる | メソッドをクリック → 「似た処理を持つメソッドと統合」 | 同じ処理を持つメソッドが別の場所にあると、エディタに候補が出ます。統合すると1つのメソッドになり、呼び出し元はすべてそれを呼ぶようになります。 |
| 呼び出し元へ戻す | メソッドをクリック → 「呼び出し元へ戻す」 | 抽出したメソッドや横流しするだけのメソッドの中身を、呼び出し元へ書き戻して消します(Inline Method)。 |
| 公開範囲を変える | メソッドをクリック → 「可視性」 | public / protected / private を選べます。可視性を扱うステージでだけ表示されます。 |

### メソッドエディタの統合の欄

- 見出しを `似た処理を持つメソッドと統合` にする
- 見出しの下に1行の説明: `同じ処理を1つのメソッドにまとめます。統合したメソッドは、今選んでいるメソッドの場所に残ります`
- 名前の入力欄に、目に見えるラベル `統合後の名前` を付ける(`<label>` で入力欄とつなぐ)
- 候補のボタンの文字を `<クラス名>.<メソッド名>() と統合する` にする(`data-testid` は今の `merge-candidate-<メソッド名>` のまま)

### 「呼び出し元へ戻す」

- ボタンに `title` を付ける: `このメソッドの中身を呼び出し元へ書き戻して、このメソッドを消します`
- ボタンの下に、同じ内容の短い説明を小さく出す

## TDD対象の純粋関数

なし(表示の文言の変更)。E2E で確かめる。

## 受け入れ基準

1. 操作ガイドに「似た処理をまとめる」「呼び出し元へ戻す」「公開範囲を変える」の3項目がある
2. 中級9で2つのサービスから消費税の処理を抽出してメソッドを選ぶと、統合の欄の見出しが「似た処理を持つメソッドと統合」になり、ボタンが「InvoiceService.calculateInvoiceTax() と統合する」になっている
3. 統合後の名前の欄に、目に見えるラベル「統合後の名前」がある。ラベルを押すと入力欄にフォーカスが移る
4. 「呼び出し元へ戻す」に、何が起きるかの説明が出る
5. 既存の統合・インライン化の E2E が通る
6. `npm run check` と `npm run test:e2e` が通る

## スコープ外

- 統合・呼び出し元へ戻すの操作そのものの変更(ドラッグでの統合など)
- 右クリックメニューへの統合の追加
- 初回ツアーへの統合・戻すの手順の追加
